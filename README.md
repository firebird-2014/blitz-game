# BLITZ 🎮

A fast-paced reaction click game built by Phoenix & Dad.

🕹️ **[Play it here](https://monumental-taiyaki-f2ddb3.netlify.app)**

---

## How to Play

Click targets before they disappear and before the storm bar runs out. Miss too many and you lose a life — lose all 3 and it's game over.

- **Llamas / Creepers / Noobs** — +10 pts
- **Chests / Diamonds / Gears** — +20–25 pts
- **Supply Drops / TNT / Gems** — +15 pts
- **Walls** — click twice to break them and reveal a sniper (+30 pts!)
- **3x combo** = double points, **6x combo** = triple points

The game gets faster every 5 seconds. How long can you last?

## Shop

Earn coins by hitting targets. Spend them in the Shop on skins that change your crosshair color and click effects. Each theme has 4 skins.

---

## Built With

- HTML, CSS, JavaScript — single file, no libraries
- All art drawn as inline SVGs
- Web Audio API for sound effects

## Run Locally

No install needed. Just open `BLITZ Game.html` in any browser.
